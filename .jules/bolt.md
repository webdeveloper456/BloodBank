## 2026-03-31 - Pre-calculated ARGB Hex Literals and Batch Adapter Notifications
**Learning:** In Android RecyclerView adapters, calling `Color.parseColor("#HEX")` in `onBindViewHolder` allocates strings and invokes regex parsing on every scroll frame. In local unit tests without Robolectric, `Color.parseColor` throws unmocked stub exceptions. Using primitive ARGB hex literals (e.g., `0xFFC13F31`) executes in 0 method calls with 0 allocations and works cleanly in local JUnit tests. Additionally, invoking `notifyDataSetChanged()` inside Firebase `DataSnapshot` loops triggers O(N) re-layout passes instead of O(1) when notified after loop completion.
**Action:** Replace `Color.parseColor` string parsing with direct ARGB integer constants in adapter binding, and ensure `notifyDataSetChanged()` is called once per dataset update rather than per item in loops.
